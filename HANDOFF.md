## Продолжение на новом ноутбуке

1. Клонировать LangTutor, открыть его, прочитать AGENTS.md и этот HANDOFF.md.
2. Проверить main/origin и рабочую копию; Node.js >=22 <26, `npm.cmd ci` на Windows.
3. Восстановить GitHub/SSH-доступ безопасно, env из секретного хранилища/Coolify,
   не из Git. Не копировать production DATABASE_URL в тесты.
4. При изменениях выполнить npm.cmd run check; PostgreSQL integration — только
   на отдельной тестовой БД. Секреты и пользовательские записи не включать в fixtures.
5. Спросить следующую задачу. Ничего не нужно повторно мигрировать, коммитить или
   активировать только потому, что сменился ноутбук. Свежий статус проверять read-only.

Автопамять Codex со старого ноутбука не гарантированно переносится. Этот файл —
переносимый источник контекста. Коммит этого документа не требует нового деплоя кода.
