# Постоянные правила проекта

LangTutor — security-first многопользовательская платформа изучения языков. Первый content pack и совместимый миграционный контур происходят из ItalianLearent. Клиент находится в `client/`, Express API — в `server/`, общие схемы и чистые функции — в `shared/`, эксплуатационные файлы — в `deploy/`.

- Использовать TypeScript strict и Zod на всех API-границах.
- Команды: `npm run dev`, `npm run build`, `npm start`, `npm run check`, `npm run db:migrate`, `npm run db:seed`.
- Секреты доступны только серверу и никогда не попадают в клиент, экспорт или логи.
- Пользовательское аудио, Blob и MediaStream не сохраняются; все tracks закрываются после попытки.
- Демо-режим без внешних сервисов обязателен.
- Учебные данные принадлежат пользователю, семейные настройки и секреты — семье; смешивать эти области запрещено.
- Интернет-аутентификацию нельзя подменять `anonymousId`, семейным кодом, IP или временем последнего доступа.
- PostgreSQL runtime-role не имеет `BYPASSRLS`; критические tenant-таблицы используют `FORCE ROW LEVEL SECURITY`.
- Все действия доступны с клавиатуры, имеют видимый focus и текстовое состояние; не полагаться только на цвет.
- Перед завершением изменения выполнить lint, typecheck, тесты, build и пропорциональный production healthcheck.
