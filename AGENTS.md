# Постоянные правила проекта

ItalianLearent — локальный русскоязычный тренажёр итальянского A0–A1. Клиент находится в `client/`, Express API и SQLite — в `server/`, общие схемы, контент и чистые функции — в `shared/`, эксплуатационные файлы — в `deploy/`.

- Использовать TypeScript strict и Zod на всех API-границах.
- Команды: `npm run dev`, `npm run build`, `npm start`, `npm run check`, `npm run db:migrate`, `npm run db:seed`.
- Секреты доступны только серверу и никогда не попадают в клиент, экспорт или логи.
- Пользовательское аудио, Blob и MediaStream не сохраняются; все tracks закрываются после попытки.
- Демо-режим без внешних сервисов обязателен.
- Все действия доступны с клавиатуры, имеют видимый focus и текстовое состояние; не полагаться только на цвет.
- Перед завершением изменения выполнить lint, typecheck, тесты, build и production healthcheck.
