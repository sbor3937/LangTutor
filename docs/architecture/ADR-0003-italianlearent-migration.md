# ADR-0003: совместимая миграция ItalianLearent

- Статус: принят
- Дата: 2026-08-23

## Решение

ItalianLearent остаётся неизменяемым источником миграции. Старый `anonymousId` сохраняется как legacy UUID и связывается с новым аккаунтом только после подтверждённой аутентификации. Семейный recovery code и PIN не становятся интернет-учётными данными.

Импорт SQLite выполняется транзакционно и идемпотентно. Повторный запуск не создаёт дубликатов и не уменьшает счётчики прогресса, попыток или словаря. Перед импортом создаётся проверяемая резервная копия; после него сравниваются контрольные показатели по каждому пользователю.

## Совместимость

До завершения parity tests SQLite-контур сохраняется как read/migration source. Переключение production допускается только после проверенного восстановления PostgreSQL backup.
