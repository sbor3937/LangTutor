# ADR-0001: модульный монолит

- Статус: принят
- Дата: 2026-08-23

## Решение

LangTutor начинается как TypeScript-модульный монолит: React-клиент, Express API, PostgreSQL, Redis и отдельный процесс worker из одной кодовой базы. Контейнеры web/API и worker собираются из одного commit.

## Причины

Модель обеспечивает транзакционную целостность переходов между семьями, единый security boundary и низкую эксплуатационную стоимость. Границы доменов остаются явными, поэтому AI Gateway или аналитика позднее могут быть вынесены без изменения продуктовой модели.

## Ограничения

Запрещены Prisma, NestJS, Next.js, tRPC, GraphQL и преждевременное разделение на микросервисы. Сетевой вызов не используется там, где достаточно внутрипроцессного application service.
